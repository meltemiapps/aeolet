# Security policy

Please report security problems in Aeolet privately, by email to **developer@meltemiapps.co.uk**. Do not open a public GitHub issue, pull request or discussion for them.

Useful things to include:

- what the problem is and what an attacker could do with it
- steps to reproduce, or a proof of concept
- the Aeolet version and the iOS version you tested on

We will acknowledge your report and keep you updated while we work on a fix. Please allow a reasonable time for a fix to be released before you disclose the problem publicly.

## Scope

In scope: the Aeolet iOS app and the code in this repository, including OAuth sign-in, token storage, the mail cache, the PGP code and how remote content is blocked.

Out of scope: Gmail and Google's own services, keys.openpgp.org, and problems that need a jailbroken or already compromised device.
